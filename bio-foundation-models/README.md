# Bioinformatics Foundational Models Directory

## Project Goal
Provide an agent-friendly, structured directory of bioinformatics foundational models with consistent metadata and per-model descriptors.

## Usage for AI Agents
1. Read `AGENTS.md` for agent workflow conventions.
2. Parse `index.yaml` to discover all models and slugs.
3. Navigate to `models/<slug>/model.yaml` for model-level metadata and deployment hints.
